# ASLSTORE.KZ — JavaScript и jQuery (Endterm)

Магазин уличной унисекс-одежды в Астане. Тот же репозиторий, команда и страницы, что с мидтерма.
После мидтерма HTML и CSS не менялись: добавлялись только теги `<script>`, а кнопка «← Назад» удалена по указанию преподавателя.
Всё новое создаётся кодом, внешний вид меняется только переключением готовых классов (`hidden`, `active`, `selected`, `is-invalid` и др.).

## Чистый JS и jQuery разделены по файлам

| Файл | Часть | Где подключён | Что делает |
|---|---|---|---|
| `js/data.js` | чистый JS, **без DOM** | все страницы, первым | данные на вершине файла (`PRODUCTS`: 37 товаров, цены, размеры), корзина в localStorage, расчёты суммы и доставки, проверки имени, телефона и email |
| `js/main.js` | чистый JS | все страницы | кнопки «В корзину» / «Заказать» (делегирование на `<main>`), счётчик в шапке, `createEl()`, `setFieldError()` |
| `js/catalog.js` | чистый JS | clothing, shoesandacc | поиск, фильтр по разделам, сортировка, счётчик «Найдено N из M», «Ничего не найдено», сброс |
| `js/size-finder.js` | чистый JS | clothing | подбор размера по росту и обхвату груди (как «Find your size» у Adidas), выбор размера во всех карточках |
| `js/countdown.js` | чистый JS | sale | живой таймер до конца распродажи (15 ноября), обновляется каждую секунду |
| `js/order.js` | чистый JS | order | корзина (размер, + / −, удаление через делегирование), итог с доставкой, **главная форма** с полной валидацией, резюме с демо-номером |
| `js/feedback.js` | **jQuery** | colophon | форма «Задать вопрос»: валидация, счётчик символов, карточки вопросов, эффекты |
| `js/gallery.js` | **jQuery** | index, clothing, shoesandacc, sale | увеличение фото товара по клику, Enter или Escape |
| `js/minicart.js` | **jQuery** | index, clothing, shoesandacc, sale | мини-корзина «Добавлено в корзину» (как у Nike): фото, размер, сумма, полоса до бесплатной доставки, «Оформить заказ» |
| `js/quickview.js` | **jQuery** | index, clothing, shoesandacc, sale | «Быстрый просмотр»: окно с большим фото, ценой со скидкой, размерами-кнопками и «В корзину» |
| `js/old-js-version.js` | — | не подключён | старые версии функций из Assignment 6 для сравнения |

`data.js` не трогает страницу, поэтому его функциями пользуются обе части. Внутри одной функции JS и jQuery не смешиваются: в JS-файлах нет `$`, в jQuery-файлах нет `getElementById` и `addEventListener`.
jQuery 3.7.1 подключается с CDN только на тех страницах, где есть jQuery-файлы. На order.html его нет.

## Чек-лист требований Endterm

### Чистый JavaScript

| Требование | Где |
|---|---|
| Данные в массивах и объектах на вершине файла | `PRODUCTS`, константы доставки в `data.js`; `SORT_OPTIONS` в `catalog.js`; `SIZE_CHART` в `size-finder.js`; `SALE_END`, `TIMER_PARTS` в `countdown.js` |
| Элементы генерируются циклами | строки корзины (`cart.forEach` в `order.js`), ячейки таймера (`TIMER_PARTS.forEach`), варианты сортировки, размеры в быстром просмотре (`$.each`) |
| Свои функции с параметрами и `return` | `findProduct`, `calcLineTotal` → `findProduct`, `calcSubtotal` → `calcLineTotal`, `calcDelivery`, `filterProducts`, `sortProducts`, `recommendSize` → `sizeIndexFor`, `timeLeft` |
| Условия | `if/else`, `switch` в `sortProducts`, тернарный оператор |
| Вычисляемое число | итог заказа: товары × количество + доставка; остаток до бесплатной доставки; дни/часы/минуты до конца распродажи; рекомендуемый размер |
| События в коде, разные типы | `click`, `input`, `change`, `keydown`, `focusout`, `submit`, `storage` |
| Делегирование | `<main>` → `.add-to-cart` (`main.js`), `#cart-items` → + / − / удалить / размер (`order.js`), панель разделов (`catalog.js`), события формы |
| Главная форма полностью валидирована | `order.js`: имя (`trim`), телефон, email, количество, оплата, согласие, составное правило «курьер → адрес»; ошибки рядом с полями, исчезают при исправлении |

### jQuery

| Требование | Где |
|---|---|
| CDN + `$(function () { … })` | `feedback.js`, `gallery.js` |
| Селекторы | `#fb-name`, `.product-img`, `main .product-img.selected`, `nav[...]`, `:not`, `.not($img)` |
| Обход: `.closest()`, `.find()`, `.siblings()`, `$(this)` | `productTitle()`: `.closest('.product-card').find('.card-title')`; `$img.siblings('.badge')`; `$(this)` во всех обработчиках |
| Цепочки из 3+ методов | `zoomOut()` (с комментарием к каждому звену), `buildQuestionCard()`, счётчик символов |
| Анимации | `.animate({ maxHeight })` с callback, `fadeIn/fadeOut` мини-корзины и окна, `fadeTo` затемнения, `slideDown/slideUp` ошибок; callback после закрытия окна открывает мини-корзину |
| Делегирование | `$('main').on('click', '.product-img', …)`, `$('main').on('click', '.js-quick-view', …)`, `$('body').on('click', '.js-qv-size', …)` — кнопки созданы кодом |
| Цепочка с комментарием к каждому звену | выбор размера в `quickview.js`, `zoomOut()` в `gallery.js` |

### Технические требования

- В консоли нет ошибок. Проверено на всех 6 страницах.
- Адаптивность: сетка Bootstrap (`col-12 col-md-6 col-lg-4`), проверено на 375px, 768px и десктопе.
- Нет `var`, `==`, `innerHTML` с вводом пользователя, `onclick` в HTML, `element.style`.

## Как проверить

1. clothing.html: найдите «худи», выберите раздел, отсортируйте по цене, нажмите «Сбросить». Нажмите на фото — оно увеличится. Внизу в «Таблице размеров» введите рост 178 и грудь 96 → «Подобрать» → «Выбрать L во всех карточках».
2. Нажмите «В корзину» — справа вверху появится мини-корзина. Нажмите «Быстрый просмотр» на худи, выберите размер, «В корзину».
3. sale.html: таймер до конца распродажи идёт каждую секунду. «Быстрый просмотр» показывает старую цену и процент скидки.
4. Откройте корзину. Поменяйте количество, удалите строку.
5. Нажмите «Оформить заказ» с пустыми полями: ошибки появятся у полей, фокус встанет на первую.
6. Заполните форму: появится резюме с демо-номером, корзина очистится.
7. colophon.html: отправьте вопрос с ошибкой, потом правильно.
8. F12 → Console: ошибок нет.
