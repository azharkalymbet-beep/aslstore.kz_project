1. Откройте clothing.html, найдите «худи», отфильтруйте раздел, отсортируйте по цене, нажмите «Сбросить».
2. Добавьте пару вещей (на скидках — «Заказать»), откройте корзину.
3. Нажмите «Оформить заказ» с пустыми полями: появятся ошибки, фокус на первой.
4. Заполните форму: появится резюме с демо-номером, корзина очистится.
5. Консоль браузера (F12) должна быть без ошибок.

## Вопросы на защите — короткие ответы

- **`.text()` vs `.html()`**: `.text()` вставляет строку как текст (теги выводятся буквами), `.html()` разбирает её как разметку. Ввод пользователя — только `.text()`, иначе можно вставить вредный код.
- **`.attr()` vs `.prop()` на checkbox**: `.attr('checked')` — атрибут из HTML при загрузке, после клика не меняется; `.prop('checked')` — текущее состояние `true/false`.
- **Делегирование**: обработчик висит на постоянном родителе (`#cart-items`) и ловит всплывший клик от кнопок, созданных позже. Прямая привязка к `.js-cart-plus` срабатывает только для кнопок, которые уже были на странице.
- **Эквивалент на чистом JS**: `$('#id')` → `document.getElementById('id')`, `.on('click', fn)` → `addEventListener('click', fn)`, `.toggleClass('a', x)` → `classList.toggle('a', x)`, `.text(t)` → `textContent = t`.
