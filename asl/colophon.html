Информация о разработке

Данный сайт был разработан в рамках учебного задания по курсу Web-разработки. Все страницы выполнены в строгом соответствии с требованиями чистого HTML5 без использования CSS-стилей и JavaScript.

Автор проекта: Батырғали Ақдана ™

Город: Астана, Казахстан («Столица спорта»)

Пример кода и горячих клавиш (Обязательные теги по ТЗ)

Для сохранения изменений в файле верстки используйте комбинацию Ctrl + S (или Cmd + S на macOS).

Ниже представлен фрагмент HTML-кода, отвечающий за создание структуры шапки:

<header>
    <h1>Спортивный магазин Limpopo Sport</h1>
    <nav>
        <ul>
            <li><a href="index.html">Главная</a></li>
        </ul>
    </nav>
</header>

При успешной проверке формы валидатор выдает системное сообщение: Document checking completed. No errors found.
