ℹ️ О ПРОЕКТЕ (КОЛОФОН)

Информация об авторстве, используемых технологиях и структуре ресурса.

📍 Информация о проекте и авторстве

Данный веб-сайт разработан в рамках учебного курса по веб-технологиям для интернет-магазина aslstore.kz, расположенного по адресу: г. Астана, ТД «Гүлжан», 2 этаж, бутик 246.

🛠️ Использованные технологии и стандарты

  • Стандарт верстки: Чистый HTML5, CSS3 & Bootstrap v5.3.3 (без JavaScript).
  • Валидация: Код проверен и соответствует спецификации W3C HTML5 Validator.
  • Семантические теги: <header>, <nav>, <main>, <section>, <article>, <footer>.
  • Инструменты разработки: Visual Studio Code, Git, GitHub Pages.

🗺️ Карта и структура страниц сайта

Имя файла Название страницы Основное назначение
index.html Главная страница Приветствие, популярные товары и общая информация о бутике 246.
clothing.html Одежда Каталог оверсайз одежды унисекс (футболки, худи, брюки).
shoesandacc.html Обувь и аксессуары Каталог обуви, кепок и сумок с сеткой товаров.
sale.html СКИДКИ Акционные товары со скидками и сводной таблицей распродажи.
order.html Оформить заказ HTML-форма для оформления покупки и ввода контактных данных.
colophon.html О нас (Колофон) Техническое описание проекта, стандарты и карта сайта.

📜 История разработки

  1. Проектирование семантической структуры страниц в HTML5.
  2. Подготовка и оптимизация изображений товаров в папке imagess/.
  3. Оформление CSS-стилей, добавление эффекта наведения и фиолетового оформления.
  4. Публикация готового статичного сайта на GitHub Pages.
